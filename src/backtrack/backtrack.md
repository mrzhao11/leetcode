# Backtracking（回溯）总结

## 回溯本质

所有回溯过程都可以画成一棵 **N 叉树**：

* 每一层：代表递归的深度（第几步决策）
* 同一层分支：代表这一层可做的不同选择
* 整棵树：代表所有可能路径
* 搜索目标：遍历所有从根到叶子的路径（叶子常对应一个完整解）

**记忆方式：**

```
集合大小 = 树的宽度（每个节点孩子数）
递归深度 = 树的高度（决策步数）
```

---

## 回溯通用模板

```java
void backtracking(参数) {

    if (终止条件) {
        存放结果;
        return;
    }

    for (本层每个可选元素 x) {

        做选择;

        backtracking(下一状态);

        撤销选择;
    }
}
```

---

# 一、什么时候使用 `startIndex`

## 用于：组合 / 子集 / 不关心顺序 / 元素不能重复使用

**特点：**

* 不允许回头选
* 防止出现 `[1,2]` 和 `[2,1]`
* 控制下一层从哪里开始

```java
for (int i = startIndex; i < n; i++) {
    path.add(nums[i]);
    backtracking(i + 1);   // 不可重复使用元素
    path.removeLast();
}
```

**记忆：**

```
不允许回头选 → startIndex → i+1
```

---

# 二、什么时候 `backtracking(i)` vs `backtracking(i+1)`

## 1）`backtracking(i+1)` —— 元素只能用一次

用于：

* 组合
* 子集

例：选了 `nums[i]`，下一层不能再选它

---

## 2）`backtracking(i)` —— 元素可以重复使用

用于：

* 组合总和（Combination Sum）
* 完全背包型搜索

例：选了 `nums[i]`，下一层还能继续选它

---

**记忆：**

```
可重复 → i
不可重复 → i+1
```

---

# 三、什么时候使用 `used[]`

## 用于：排列问题（顺序重要）

**特点：**

* 每一层都可以选任意元素
* 每个元素只能使用一次
* 需要标记哪些元素已用

```java
for (int i = 0; i < n; i++) {

    if (used[i]) continue;

    used[i] = true;
    path.add(nums[i]);

    backtracking();

    path.removeLast();
    used[i] = false;
}
```

**记忆：**

```
顺序重要 → 排列 → used[]
```

---

# 四、什么时候使用 `Set` 去重

## 用于：输入数组含重复元素

否则会产生重复解，例如：

```
nums = [1,1,2]

可能得到：
[1,2]
[1,2]   ← 重复
```

---

## 推荐方法：排序 + 剪枝（更高效）

```java
Arrays.sort(nums);

for (int i = startIndex; i < n; i++) {
    if (i > startIndex && nums[i] == nums[i - 1]) continue;
}
```

用于：

* 组合 II
* 子集 II
* 排列 II

---

# 五、四类回溯问题对照表

| 问题类型  | 顺序重要 | 可重复使用 | 是否需要去重 | 使用方法               |
| ----- | ---- | ----- | ------ | ------------------ |
| 子集    | 否    | 否     | 有时     | `startIndex + i+1` |
| 组合    | 否    | 否     | 有时     | `startIndex + i+1` |
| 组合总和  | 否    | 是     | 有时     | `startIndex + i`   |
| 排列    | 是    | 否     | 有时     | `used[]`           |
| 排列 II | 是    | 否     | 是      | `used[] + 排序剪枝`    |

---

# 六、核心判断口诀

## 1）顺序是否重要？

```
重要 → 排列 → used[]
不重要 → 组合 / 子集 → startIndex
```

---

## 2）元素是否可重复？

```
可重复 → backtracking(i)
不可重复 → backtracking(i+1)
```

---

## 3）输入是否含重复元素？

```
有 → 排序 + 剪枝（或 Set）
无 → 不需要去重
```
