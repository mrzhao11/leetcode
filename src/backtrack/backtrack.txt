所有回溯过程都可以画成一棵 N 叉树：
    每一层：代表递归的“深度”，也就是当前决策的第几步；
    同一层的分支：代表这一层可以做的不同“选择”；
    整棵树：就是“所有可能的选择路径”。
所以你可以这样记：
    集合的大小 = 树的宽度（每个节点的孩子数）
    递归的深度 = 树的高度（决策的步数）
搜索一般要做到 遍历所有从根到叶子的路径，叶子节点常常对应“一个完整的解”。


void backtracking(参数) { // 一般返回void，答案通过全局变量或者引用参数返回
    if (终止条件) { // 到达叶子节点或者满足某个条件
        存放结果;
        return;
    }

    for (本层可选择的每一个元素 x) {
        处理当前选择 x（加入 path / 标记已使用）;
        backtracking(基于当前选择的新的状态); // 递归，继续往下一层搜
        撤销选择 x（从 path 中移除 / 取消标记）; // 回溯
    }
}
