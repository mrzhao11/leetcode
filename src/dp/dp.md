# ✅ **动态规划总结（融合背包内容 · 最终框架版）**

## 1. 动态规划是什么（核心思想）

动态规划（DP）适用于：

1. **重叠子问题（overlapping subproblems）**
2. **最优子结构（optimal substructure）**

大白话：

> **DP = 把大问题拆成小问题，小问题的答案存起来，组合出大问题的答案。**

DP 与贪心的区别：

* **DP**：需要依赖过去的状态，是“全局最优”
* **贪心**：只看一步，不保证全局最优

---

# 2. DP 五步曲（必背模板）

1. **定义状态 dp[…] 表示什么**（最重要！）
2. **状态转移方程（递推公式）**
3. **初始化（base case）**
4. **遍历方向（顺序决定正确性）**
5. **手动推一个例子验证**

口诀：

> **定义 → 转移 → 初始化 → 遍历顺序 → 手推**

---

# 3. DP 如何 Debug（最强方法）

DP 错误 ≠ 代码错
90% 是因为：

* dp 含义错
* 初始化错
* 遍历顺序错

Debug 三步：

1. 手推一个最小例子
2. 打印 dp 数组
3. 对比手推结果与代码输出是否一致

# 4. DP 刷题路线图（体系版）

## A. 一维线性 DP（递推类）

包含爬楼梯、打家劫舍、子序列、区间 DP、编辑距离等。
核心思想：**以 i、以 i 结尾、前 i 个字符、区间 [l,r] 等。**

# B. 背包问题（最重要、最易混淆的 DP 类型）

背包问题的关键不在公式，而在 **遍历顺序**。

---

## **🟩（1）背包四大核心递推公式（分类背诵）**

### **① 问能否装满 / 最多能装多少（可行性 or 最大容量）**

```
dp[j] = max(dp[j], dp[j - weight] + weight);
```

用于可行性、最大能装多少容量类型问题。

---

### **② 问装满背包有几种方法（组合数）**

```
dp[j] += dp[j - weight];
```

代表：**方案数累加**。

> 顺序无关 → 组合

---

### **③ 问装满背包的最大价值**

```
dp[j] = max(dp[j], dp[j - weight] + value);
```

这是最标准的背包价值模型。

---

### **④ 问装满背包所需物品数量最少（最少硬币数）**

```
dp[j] = min(dp[j], dp[j - weight] + 1);
```

用于最小次数、最小数量类问题。

---

## 🟩（2）背包的遍历顺序（最核心的核心）

### **① 01 背包（每个物品只能用一次）**

| dp 定义 | 遍历顺序                              |
| ----- | --------------------------------- |
| 二维 dp | 物品、容量 → 顺序无所谓（内层倒序仍必需）            |
| 一维 dp | **outer：物品，inner：容量倒序 j=index→0** |

**倒序原因**：避免一个物品被重复使用。

---

### **② 完全背包（物品可用无限次）**

| 想求的内容     | 遍历方式             |
| --------- | ---------------- |
| 最大价值类     | 物品外层 + 容量 **正序** |
| 组合数（顺序无关） | **外层物品，内层容量正序**  |
| 排列数（顺序相关） | **外层容量，内层物品**    |
| 求最小数      | 两种顺序都可以          |

总结：

> **完全背包 = 正序遍历**
> **01 背包 = 倒序遍历**

并且：

> **组合数：物品外层**
> **排列数：容量外层**

你已经理解的零钱兑换、组合总和 IV、完全平方数都属于这些模式。

---

## 🟩（3）背包四大类的最强记忆口诀

```
01 背包倒着走：
    j 从大到小（避免重复拿）

完全背包正着走：
    j 从小到大（允许重复拿）

组合数看物品：
    物品外层（顺序无关）

排列数看容量：
    容量外层（顺序敏感）
```

这是所有背包题目背后的统一结构。

# 5. 其他 DP（略）

区间 DP（戳气球）、树形 DP（偷房子三）、状态压缩 DP（TSP），
本质都基于“状态定义 + 状态转移 + 遍历顺序”。
