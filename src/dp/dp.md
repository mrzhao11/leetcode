## 1. 动态规划是什么（What is DP）

**一句话**：DP 适合解决**有大量重叠子问题**、且**当前最优解能由前一状态推导**的问题。

* **核心特征**

  1. **重叠子问题 (Overlapping Subproblems)**：同一子问题会反复出现。
  2. **状态推导 (State Transition)**：`dp[i]`/`dp[j]` 必须能由更小/更早的状态推出。

* **DP vs 贪心 (Greedy)**

  * **DP**：有明确的“前→后”状态链，靠递推找整体最优。
  * **贪心**：每一步只看局部最优，不依赖之前状态。
  * 结论：**只靠局部选最优的题，DP 不一定需要；但需要全局权衡的题，贪心常失败。**

* **例子（01背包）**
  `dp[j] = max(dp[j], dp[j-weight[i]] + value[i])`
  体现了：**当前容量 j 的最优值来自“之前容量 j-weight[i] 的最优值 + 当前物品价值”。**

## 2. 动态规划五步曲（必背模板）

做 DP 题不是背公式，而是**按流程建模**：

1. **确定 dp 数组及其含义**

   * `dp[x]` 表示什么？（最重要！）
   * 下标 x 是“第几个/多大/到哪里/前缀长度/容量/坐标”…？

2. **确定递推公式（状态转移）**

   * 找到“当前状态 ← 哪些之前状态”。
   * 写出 `dp[...] = f(dp[...])`。

3. **dp 初始化**

   * 初值一定要和 dp 含义匹配。
   * **很多时候初始化是被递推公式倒逼出来的**。

4. **确定遍历顺序**

   * 你要保证：**用到的状态已经被算过**。
   * 例如 01 背包必须倒序遍历容量，完全背包必须正序。

5. **举例推导 dp 表**

   * 手动推一遍小例子，确认递推、初始化、顺序是否能得到目标答案。

// 1. 定义：dp[i] / dp[i][j] 表示什么？
// 2. 初始化：根据题意给 dp 赋初值
// 3. 遍历顺序：for i ... for j ...
// 4. 状态转移：dp[...] = f(dp[更小的下标...])
// 5. 返回答案：dp[n-1] / dp[n][m] / 在 dp 中找 max/min
> **口诀**：**定义 → 转移 → 初始化 → 顺序 → 手推验证**

## 3. DP 应该如何 Debug（黑盒→白盒）

DP 卡住的原因通常就三类：
**含义没想清、初始化错、遍历顺序错**。

### 最有效的 debug 方法：

1. **先手推 dp 表**（小例子）
2. **再打印 dp 数组/表**
3. 对比：

   * **如果打印结果 ≠ 手推预期** → 代码细节错（下标、边界、循环）
   * **如果打印结果 = 手推预期但答案错** → 你的建模错
     （转移公式/初始化/遍历顺序某一步有问题）

> 你文里的“灵魂三问”可以浓缩成：

* 我手推过 dp 表吗？
* 我打印过 dp 表吗？
* 两者一致吗？

## 4. 动态规划刷题大纲（路线图）

给你一个“从易到难”的刷题树，基本覆盖 LeetCode 主流 DP：

### A. 一维 DP（Linear DP）

1. **基础递推（整数/阶梯/路径）**

   * 斐波那契/爬楼梯/打家劫舍 I
   * 关键词：`dp[i] = dp[i-1] + ...`

2. **最大/最小子结构（Subarray/Subsequence）**

   * 最大子数组和 (Kadane/DP)
   * 最长递增子序列 LIS
   * 关键词：以 i 结尾/到 i 为止

3. **字符串 DP（String DP）**

   * 编辑距离
   * 最长公共子序列 LCS
   * 回文子串/回文子序列
   * 关键词：`dp[i][j]`，区间/前缀匹配

---

### B. 背包 DP（Knapsack Family）

1. **01 背包**（每件物品最多拿 1 次）

   * 目标和、分割等和子集、最后一块石头
   * 特征：容量 **倒序遍历**

2. **完全背包**（物品无限次）

   * 零钱兑换、组合总和 IV
   * 特征：容量 **正序遍历**

3. **多重背包 / 分组背包**

   * 有数量限制 / 分组只能选一个
   * 特征：转移更复杂，但本质还是背包

---

### C. 区间 DP（Interval DP）

* 合并石头、戳气球、矩阵链乘
* 常见形式：
  `dp[l][r] = min/max(dp[l][k] + dp[k][r] + cost(l,r))`
* 关键：**长度从小到大枚举区间**

---

### D. 树形 DP（Tree DP）

* 打家劫舍 III、二叉树最大路径和
* 关键：

  * 以节点为状态
  * 后序遍历
  * 常有“选/不选”两种 dp

---

### E. 状态压缩 DP（Bitmask DP）

* 旅行商 TSP、配对/覆盖类
* 状态是集合：`dp[mask]`
* 关键：mask 表示已选集合

---

### F. 其他高频 DP 思想

* **概率/期望 DP**（博弈、随机过程）
* **数位 DP（Digit DP）**
* **DP + 单调队列/栈优化**（滑窗优化转移）
