# 深度优先搜索（DFS）理论基础（简要版）

## 一、DFS 与 BFS 的区别

* **DFS（深度优先搜索）**：
  认准一个方向一直往下搜，走到尽头再回头（**回溯**），换下一个方向继续搜索。
* **BFS（广度优先搜索）**：
  先把当前节点能到的所有节点遍历完，再一层一层向外扩展。

DFS 更像“先走到黑”，BFS 更像“水波扩散”。

---

## 二、DFS 的搜索过程（核心思想）

DFS 的关键有两点：

1. **搜索方向**
   从当前节点出发，选择一条路径一直向下，直到不能继续。
2. **回溯换方向**
   当前路径走不通，就撤销当前选择，回到上一个节点，改走另一条路径。

👉 回溯的作用：**撤销当前路径的选择，尝试其他可能性**。

---

## 三、DFS 为什么适合用递归

* DFS 天然具备“深入 + 回退”的结构
* **递归向下 = 搜索**
* **递归返回 = 回溯**

因此 DFS 用递归实现最直观、最不容易出错。

---

## 四、DFS 的代码框架（通用思想）

```text
void dfs(参数) {
    处理当前节点
    for (选择：当前节点能到达的所有节点) {
        做选择
        dfs(选择的节点)   // 递归
        撤销选择（回溯）
    }
}
```

这和回溯算法的框架本质是一致的。

---

## 五、深搜三部曲

### 1️⃣ 确认递归函数及参数

```text
void dfs(当前节点, 其他必要参数)
```

常见做法：

* 用一个一维数组保存**当前路径**
* 用一个二维数组保存**所有结果**
* 结果数组常设为全局变量，减少参数复杂度

---

### 2️⃣ 确认终止条件

```text
if (到达目标 / 不满足条件) {
    保存结果;
    return;
}
```

⚠️ 终止条件是 DFS 是否正确的关键，很多死循环问题都出在这里。

---

### 3️⃣ 处理当前节点的所有选择（回溯）

```text
for (选择：当前节点的所有相邻节点) {
    处理节点;
    dfs(下一个节点);
    回溯，撤销处理结果;
}
```

回溯的本质：
👉** ****让程序在同一个节点上，尝试不同的搜索方向**。

---

# Java 模板（保留 DFS 原始风格）

## 模板一：DFS 遍历图（不需要保存路径）

```java
void dfs(int node) {
    visited[node] = true;          // 处理当前节点
    for (int next : graph[node]) { // 遍历相邻节点
        if (!visited[next]) {
            dfs(next);             // 递归
        }
    }
}
```

适用场景：

* 图遍历
* 连通分量
* 是否可达

---

## 模板二：DFS + 回溯（保存所有路径）

```java
List<List<Integer>> result = new ArrayList<>();
List<Integer> path = new ArrayList<>();
boolean[] used;

void dfs(int node, int target) {
    if (node == target) {                 // 终止条件
        result.add(new ArrayList<>(path));
        return;
    }

    for (int next : graph[node]) {        // 枚举选择
        if (used[next]) continue;

        used[next] = true;                // 做选择
        path.add(next);

        dfs(next, target);                // 递归

        path.remove(path.size() - 1);     // 回溯
        used[next] = false;
    }
}
```

适用场景：

* 找所有路径
* 回溯搜索类问题
* 图中路径枚举

---

## 六、总结

* **DFS = 搜索 + 回溯**
* **回溯不是额外操作，而是 DFS 正常执行的一部分**
* DFS、回溯、二叉树递归，本质上是同一套思想
* 写 DFS 时，牢牢记住** ****深搜三部曲**

> 只要三部曲想清楚，DFS 代码自然就能写出来。
